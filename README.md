# Monitorizare Depozit

## Descriere

Monitorizare Depozit este o aplicație dezvoltată în limbajul C++, utilizând principiile Programării Orientate pe Obiecte, pentru administrarea și monitorizarea stocurilor dintr-un depozit.

Aplicația permite gestionarea produselor și furnizorilor, efectuarea tranzacțiilor de intrare și ieșire marfă, monitorizarea nivelului stocurilor și generarea automată a comenzilor de reaprovizionare.

## Obiective

* evidența produselor existente în depozit;
* gestionarea furnizorilor;
* monitorizarea stocurilor și a pragurilor minime;
* înregistrarea tranzacțiilor efectuate;
* păstrarea istoricului tranzacțiilor în fișiere;
* generarea automată a comenzilor de reaprovizionare;
* oferirea unei interfețe intuitive pentru utilizator.

## Funcționalități implementate

### Gestionare produse

* adăugare produse;
* eliminare produse;
* afișare stocuri;
* asociere furnizor pentru fiecare produs.

### Gestionare furnizori

* adăugare furnizori;
* afișare furnizori;
* asociere furnizor-produs.

### Gestionare stoc

* tranzacții de intrare marfă;
* tranzacții de ieșire marfă;
* actualizare automată a cantităților.

### Monitorizare

* raport produse sub pragul minim;
* dashboard cu statistici;
* evidențiere vizuală a produselor critice.

### Persistență

* salvarea produselor în fișiere text;
* salvarea furnizorilor în fișiere text;
* salvarea istoricului tranzacțiilor.

### Reaprovizionare

* generarea automată a comenzilor către furnizori;
* creare fișiere separate pentru fiecare furnizor.
